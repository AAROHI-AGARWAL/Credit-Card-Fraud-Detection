# Credit Card Fraud Detection Using Anomaly Detection Techniques

## Project Objective

The objective of this project is to develop a machine-learning-based system
for identifying potentially suspicious credit-card transactions using
anomaly detection techniques.

## Main Techniques

- Exploratory Data Analysis
- Data Preprocessing
- Feature Engineering
- Isolation Forest
- Autoencoder
- Anomaly Scoring
- Risk Classification
- Fraud Alert Generation

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- PyTorch

- MySQL
